# Лабораторна робота 8

**Варіант 10:** Система обліку замовлень ресторану  
**Сутності:** Стіл (`RestaurantTable`, 1) та Замовлення (`Order`, N)  

## Опис проєкту
Консольний застосунок C++20 для автоматизації обліку столів у ресторані та пов'язаних із ними замовлень. Проєкт демонструє відображення моделей на реляційну БД SQLite за допомогою бібліотеки `sqlite_orm`, використання патерна Repository, формування запитів (фільтрація, сортування, агрегація `SUM`, `INNER JOIN`) та забезпечення цілісності даних за допомогою транзакцій (`COMMIT` / `ROLLBACK`).

## Використовуваний стек
- **Мова програмування:** C++20
- **Система збирання:** CMake (версія 3.20+)
- **Пакетний менеджер:** vcpkg (Manifest mode)
- **База даних:** SQLite 3
- **ORM-бібліотека:** `sqlite_orm`

## Вимоги до середовища
- Visual Studio (з компонентом C++ CMake tools)
- Пакетний менеджер `vcpkg`

## Інструкція зі збирання та запуску

## Спосіб 1: Visual Studio (рекомендовано)
1. Відкрийте папку проєкту у Visual Studio: `Файл -> Открыть -> Папка...`.
2. Переконайтеся, що в налаштуваннях CMake (`CMakeSettings.json`) вказано шлях до `vcpkg.cmake`.
3. Дочекайтеся автоматичного завантаження залежностей через `vcpkg` та зчитування конфігурації CMake.
4. Натисніть **F5** або зелену кнопку **Локальный отладчик Windows** для збирання та запуску проєкту.

## Спосіб 2: Через командний рядок CMake

# 1. Створення папки збирання та генерація конфігурації
cmake -B out/build -S . -DCMAKE_TOOLCHAIN_FILE="C:/Program Files/Microsoft Visual Studio/18/Community/VC/vcpkg/scripts/buildsystems/vcpkg.cmake"

# 2. Компіляція проєкту
cmake --build out/build

# 3. Запуск виконного файлу
./out/build/Lab8_Restaurant.exe
